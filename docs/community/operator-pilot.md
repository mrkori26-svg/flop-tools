# FLOP Tools operator pilots

Independent community project; not a FLOP Labs service.

We are evaluating a limited number of opt-in pilots for agent builders who need a reproducible explanation of onboarding blockers or economic evidence gaps. The current preview is offline, read-only evidence analysis. It does not enroll agents, fund wallets, send inference requests, or certify on-chain settlement.

## Free starting point

Read the [dated Testnet readiness observation](testnet-readiness-2026-11-24.md). Compare the current official network documentation and supported SDK/runtime before relying on it.

## Pilot workflow

1. Open an issue in this repository titled `Pilot: <one concrete workflow>`.
2. Describe the task, public SDK version, network, and expected versus observed behavior. Include only public or intentionally sanitized information.
3. Agree on a minimal test case, acceptance criteria, and scope before sharing further records.
4. If a paid integration or ongoing support would help, discuss a written scope and quote separately. No price, availability, or outcome is promised by this page.

Never post credentials, signing keys, seed phrases, identity documents, private logs, or customer data. Do not submit a wallet or payment to participate. Public bug reports remain separate from any paid engagement. 

The project is retaining its advanced analysis and integration implementation privately while evaluating demand. Existing open-source code retains its license. No claim is made about airdrop eligibility, official contributor rewards, referral compensation, or customer adoption.

## Example acceptance criteria

- A stale chain observation is explicitly distinguished from a currently confirmed network state.
- An SDK runtime mismatch is reported without disabling its compatibility checks.
- A grant with uncertain outcome is marked unresolved, rather than treated as completed.
- A locally consistent receipt is not described as authenticated settlement.

Success means a reproducible, useful diagnosis with documented limits; not a guaranteed payout or faster admission.
